# 硬件与配件清单

本项目以 ESP32-S3 触摸显示开发板为主机，配合人体存在雷达、CO₂ 传感器和 microSD 卡，做一个桌面环境与电脑状态屏。下面记录项目实际使用的硬件，以及复现时需要核对的规格。现有工程没有购物订单、成交价格或可靠的商店链接，因此不把这些信息写成已确认的购买记录。

## 实际使用的配件

| 配件 | 数量 | 用途与已确认规格 |
| --- | ---: | --- |
| ESP32-S3 触摸显示开发板 | 1 块 | 实物 PCB 丝印为 **SC3248W535**；ESP32-S3-N16R8，16 MB Flash、8 MB octal PSRAM。 |
| AXS15231B QSPI 显示屏及电容触摸 | 板载 1 套 | 已包含在上面的开发板中；面板原生 320×480，固件以 480×320 横屏显示，rotation=1。触摸使用 I²C，地址为 0x3B。 |
| HLK-LD2410C 毫米波人体存在模块 | 1 个 | 读取运动/静止存在状态、摘要距离及能量，用于本地感应亮屏；固件只接收数据，不写雷达参数。 |
| Sensirion SCD41 CO₂ 模块 | 1 个 | 读取 CO₂、温度和相对湿度，通过独立 I²C 总线工作。项目未记录所用转接板的具体厂商、稳压器或连接器型号。 |
| microSD / TF 卡 | 1 张 | 保存本地动态壁纸，以及 v0.9.2 新增的环境历史。此前使用的卡约为 1 GB；没有确认品牌和标称容量。 |
| USB 数据/供电线 | 1 根 | 用于首次烧录、串口调试和开发板供电；需要可传输数据的线。插头类型按实际开发板核对。 |
| 模块接线或转接线 | 按实际接口配置 | 连接两个外置模块。工程没有可靠的插头间距、线长、线色或购买数量记录，购买前核对板端与模块端接口。 |

Mac 是电脑状态、桌面控制、视频导入和时间同步所需的 Bridge 主机，属于运行环境；不是本清单中已确认专门购买的配件。实时环境读数、人体存在状态和本地提醒可以在已配置的设备上独立运行。环境历史的日期沿用 Bridge 校时；冷启动后尚未校时会等待时间，不生成虚假的历史日期。

## 选择开发板时要核对什么

实际板丝印是 **SC3248W535**，而项目沿用的 PlatformIO 构建环境名称是 **`jc3248w535`**。环境名称不是所有 SC、JC 或外观相似开发板都兼容的保证。`board = esp32-s3-devkitc-1` 是构建目标配置，也不意味着本项目的屏幕引脚适用于任意通用 DevKit。

复现时至少核对以下内容：

- ESP32-S3-N16R8，16 MB Flash 与 8 MB octal PSRAM；项目使用 `qio_opi` 内存配置。
- AXS15231B QSPI 显示控制器及相同的显示、触摸和 SD 引脚。
- 320×480 原生面板几何和电容触摸接口。
- 扩展口实际走线是否对应本文的 GPIO；以具体板卡的丝印、原理图和测量为准。
- 传感器转接板的供电要求、逻辑电平、连接器与电源容量。

## 外置传感器的信号连接

以下表格记录已用实际通信验证的**逻辑信号映射**。它不定义连接器朝向、线色或电源针脚顺序。改变接线前先断电。

| 模块信号 | ESP32 连接 | 通信设置 | 说明 |
| --- | --- | --- | --- |
| LD2410C TX 数据输出 | GPIO44，作为 UART1 RX | 256000 baud，8N1 | 雷达发送，ESP32 接收；不要把 TX→RX 写反。 |
| ESP32 向 LD2410C 发送 | 未启用，TX=-1 | 纯接收 | 不需要为当前固件建立发送链路。主板扩展口另一方向的 UART TX 路径未验证。 |
| SCD41 SDA | GPIO17，I²C1 | 100 kHz，地址 0x62 | 使用独立的 `TwoWire(1)`。 |
| SCD41 SCL | GPIO18，I²C1 | 100 kHz，地址 0x62 | 不占用板载触摸总线。 |

两个外置模块的服务独立采样，屏幕只读取快照。板载触摸继续使用 I²C0 的 GPIO4/8，不能用传感器初始化覆盖这条总线。SCD41 的来源是实际测量读取及 CRC 检查；雷达报告是运动和静止摘要，不提供人数、目标 ID 或逐人坐标。

## 电源与电平的已知限制

历史版本已经在现有接线上完成单模块、双模块通信及有限时间的功能观察，但以下两项仍为 **BLOCKED**：

| 项目 | 状态 | 尚缺少的证据 |
| --- | --- | --- |
| 电源极性及端到端电气测量 | **BLOCKED** | 没有独立归档的电压、极性与连续性测量，不能仅由软件通信成功推导所有电源针脚都已验证。 |
| 主板 3.3 V 稳压器供电余量 | **BLOCKED** | 缺少具体实板稳压器、线路及 SCD41 峰值负载下的独立余量验证。 |

因此，本文不提供未经验证的“把某个 VCC 接到某个插座位置”指令，也不根据模块名称假定某款转接板可以接 3.3 V 或 5 V。应按所购开发板和传感器模块的具体资料核对电源、逻辑电平及共地要求，并完成独立测量。不得向 ESP32 GPIO 直接施加未经确认的电压。

成功构建、收到有效数据或观察到一段正常运行，都不能证明电气认证、无限时稳定运行或测量精度。接线需要变化时先拔掉电源；结束串口采集不会切断模块电源。

## 板载完整引脚表

以下映射来自 [`include/board_config.h`](../include/board_config.h)。屏幕、触摸和 SD 均是开发板已有连接，用于核对板型及开发参考；通常不需要另接一套这些连线。

| 功能 | 信号 | GPIO / 配置 |
| --- | --- | --- |
| QSPI LCD | CS | 45 |
| QSPI LCD | Clock | 47 |
| QSPI LCD | Data0 | 21 |
| QSPI LCD | Data1 | 48 |
| QSPI LCD | Data2 | 40 |
| QSPI LCD | Data3 | 39 |
| LCD | Tearing Effect | 38 |
| LCD | Backlight | 1 |
| LCD | Reset | -1，未分配 GPIO |
| 电容触摸 | SDA | 4 |
| 电容触摸 | SCL | 8 |
| 电容触摸 | Interrupt | 3，板级定义 |
| 电容触摸 | I²C 地址 / 频率 | 0x3B / 400 kHz |
| SD_MMC | Clock | 12 |
| SD_MMC | Command | 11 |
| SD_MMC | Data0 | 13 |
| 按钮 | BOOT | 0，低电平有效 |

SD 使用 **1-bit 模式**；不能直接改为 4-bit，其他数据线会与 QSPI 屏幕引脚冲突。固件不会因为挂载失败而自动格式化 SD。壁纸和环境历史各自使用独立目录；没有可用 SD 时，本地传感器采样仍可运行，历史存储则显示不可用状态。

## 版本与实物验证范围

本仓库的最新源码为 **v0.9.2**，包含一米范围的感应亮屏判断、雷达距离页和每日环境曲线。该版本已完成构建和离线验证。2026-10-20，作者确认设备已刷入 v0.9.2，一米内感应亮屏和空气曲线页使用正常；距离边界的精确测量、SD 历史长期写入与断电恢复尚未专门验收。

LD2410C 和 SCD41 都已接入设备并正常运行；尚未录制演示视频或归档运行日志，验收与电气测量范围见 [验证状态](VALIDATION.md)。

此前 v0.9.0 / v0.9.1 已在上述板卡和两个传感器上完成有限时间的功能观察，包含本地环境、感应亮屏、提醒及 Bridge 断线恢复。旧版本的实物结果不会自动证明 v0.9.2 的新增功能已经通过验收；电源与电平限制也继续保持上述状态。
