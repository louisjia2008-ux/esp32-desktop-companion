# 公开范围与本地数据

本仓库是独立的公开源码快照，包含固件、Bridge、网页、构建配置、测试、通用说明以及带原始许可证的字体和 QR 实现。初始历史从整理后的源码开始，未迁入其他项目或原工作目录的 Git 历史。

## 未纳入公开快照的内容

- Wi-Fi 密码、个人 SSID、实际局域网地址和设备标识。
- API 密钥、访问令牌、账号登录状态、AI 对话和完整工具日志。
- Bridge `.runtime/`：配对密钥、壁纸、信息卡、任务记录、用量状态及个人设置。
- 原始视频、截图、SD 内容、环境实测记录、设备捕获和历史验收附件。
- Flash / NVS 备份、固件恢复镜像、编译产物、虚拟环境和下载缓存。
- 本机绝对路径、固定串口号，以及针对私人音频设备编写的操作验收脚本。

保留的 `127.0.0.1`、`0.0.0.0` 和 `192.168.4.1` 分别用于本地服务、监听地址和设备 Setup AP。测试中的示例网络、全零 MAC、虚构路径和演示 ID 是固定测试输入。

## 使用时在哪里生成数据

Wi-Fi 凭据由设备配网流程写入 ESP32 Preferences / NVS。Bridge 在本机运行目录生成配对、显示、壁纸和桌面 Hub 状态。环境历史写入设备 SD 的固定历史槽，不上传到云服务。

可选 Codex / Claude Code 集成读取对应本地工具状态，并将有限状态发送到已配对小屏；信息卡、文件引用、网络名、蓝牙名和任务标题在运行时按功能需要处理。公开源码不包含用户的现有记录。不要将运行目录、环境历史或诊断捕获直接附到公开 Issue。

网页管理端固定在 `127.0.0.1:8766`，设备 WebSocket 用于可信局域网。换网络、分享文件、蓝牙控制和固件安装各有实际交互或确认流程；运行测试时区分离线回归和有真实设备副作用的显式诊断脚本。

## 后续更新的自动检查

每次新克隆后，在仓库根目录执行一次：

```sh
python3 scripts/install_privacy_guard.py
```

安装器下载并校验固定的 Gitleaks 8.30.1，为当前克隆启用提交前和推送前检查。提交前扫描实际暂存内容；推送前扫描本次推送目标及其完整可达历史，包括后来已删除的文件。项目规则补充检查 Wi-Fi / 配对凭据、运行目录、日志、备份、个人路径和设备标识。扫描工具缺失、历史不完整或检查出错时会阻止操作。详细规则、离线安装与问题处理见 [自动隐私检查](PRIVACY_GUARD.md)。

GitHub 仓库也启用了内置 secret scanning / push protection，并在 push、pull request 和手动触发时运行 `Privacy guard` 工作流。**Actions 工作流是在内容到达 GitHub 后运行，上传前的项目检查依赖已安装的本地 hooks。** GitHub 内置保护提供额外检查，但不覆盖所有 Wi-Fi、配对信息和个人日志格式。

`.gitignore` 排除了常见运行数据、密钥文件、日志、媒体、备份和构建目录。强制添加文件仍会经过已安装的检查；不过 hooks 可以被跳过，网页或 API 上传也不会运行本地 hooks。提交前仍需检查暂存差异，避免上传真实运行数据；自动扫描不能识别所有未知密钥或个人信息。
